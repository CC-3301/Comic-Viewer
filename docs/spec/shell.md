# Spec 分册：UI 骨架

> 索引与全局口径在 `docs/SPEC.md`；本文件是它的分册，只装本领域的内容。
> 故事编号全局连续（1–54）、**是稳定锚点**：删除的故事留空号、不重排（代码注释里的「spec 故事 N」据此长期有效）；新增故事一律在末尾追加新编号。

## Implementation Decisions

### UI 骨架

**三个主界面**：

- 浏览页：顶栏是**「视图」菜单 + 排序**
  - 视图档位 = 列表 / 网格 2 列 / 网格 3 列 / 网格 4 列，默认网格 2 列
  - 非法或缺失值回落网格 2 列；全 app 一份、跨目录层级与连接与重启保持
  - 手动刷新是**下拉更新**——只认拖拽、滚轮不触发
  - 条目形态随档位切换；两档共用枚举/方向/名称/进度/点击语义
  - **顶栏标题恒单行、放不下时末尾省略**
    - 根层 = 连接名，子层 = 条目名
    - 因此任何长度的名字都不折行、不撑高顶栏
    - 想看全名的补救是给连接起短名；不做标题展开/tooltip 与自适应缩小字号
- 阅读器：类型 3 触摸区域、菜单 overlay、横向预览条（全书页滑动）、上一本/下一本
- 导航抽屉：左缘，首页/阅读器/书柜/设置四个入口
  - 浏览历史的后退/前进只在系统返回手势与鼠标侧键，不再有抽屉入口

**鼠标左键按住拖动 = 上下滑动**：

- 适用浏览页两档与条漫模式
- 与下拉更新分层——顶部向下拖动整段仍只归下拉更新
- 单页模式不加

#### 快速定位滑条

**几何**：

- 浏览页两档的右缘各一条细滑条，宽 6dp、**本体居中于横向空档**
  - 离屏缘 = （空档 − 本体宽）/ 2
  - 空档 = 内容右留白 + 系统右缘 inset
  - 无系统右缘 inset 时空档 = 20dp ⇒ 本体右缘离屏缘 7dp、抓取带 13dp
  - 空档被系统右缘 inset 撑宽（横屏 / 三键导航把系统栏放右侧 / 挖孔）时，
    本体离屏缘随之变大、仍落在空档正中，抓取带随空档变宽
- 半透明叠在内容之上；**不压封面与名称**（网格档下离封面 7dp、离屏缘 7dp）
- 右侧留白 12→20dp 的代价是每格封面窄约 8dp
- 供 1000+ 条目时一步定位

**位置与长度**（都取连续值）：

- 进度 = （首个可见**行**索引 + 行内已滚过比例）÷ 总行数
- **按行不按条目**：网格档一档多格、按条目算会让行内速度减半并在每行边界跳一格
  —— 列表档一行 = 一条、算式与旧口径一致
- **按需加载的层里分母是「已加载条数」+ 截断提示行与尾部触发件行**
  （滑条表示的是**已加载范围内**的位置，更远的条目要先滚到底续页
  —— 总数要按需加载才知道，拖到未加载的位置也没有内容可落）
- 可见条目数按**各可见条目露出比例求和**（不用整数计数）
- **长度下限 64dp**——条目再多也不再变短；不足一屏或不足两条时不显示

**实现位置**：

- 几何与「拖动位移 → 目标条目索引」（网格档落点是该行的首条）收在一处纯函数
- 手势判定（**只认主键**、**越过触摸斜率才算拖动**、**滚轮换算**）收在一处状态机

**出现/隐藏**：滚动即淡入 120ms、静止 1.2 秒后**只淡出一次** 200ms
（**按住或拖动期间不计时、也不重排计时**）

**带内手势的取舍（有意）**：

- 带内起手的上下拖动 = 跳到该处（不是平滑滚动列表）
- 带内鼠标滚轮**照常滚动列表**
- 带内起手的点击归滑条（可见期间这条抓取带不传点击；完全隐藏即整条移除）

#### 返回逐级

**抽屉顶层入口压在当前界面之上**：

- 抽屉的首页/书柜/设置三个顶层入口**压在当前界面之上**
  （返回因此回到进入前的界面，例如进入设置前的那个子文件夹）
- 顶层入口不叠加、不形成环；进入新入口前先收掉栈顶连续的顶层入口层

**回退栈是唯一事实来源**：

- 浏览历史是回退栈里浏览层的**镜像**
  —— 显示每一层时按实际回退栈重建后再落盘
- 随**会话结束（Activity finish）**清空；
  旋转这类非 finish 的 Activity 重建**保留**历史
- 启动落地按**落盘路径**重建整条层级链（根 → … → 上次停留层）
- **同一层重复进入 = 替换**（不追加）
- 从抽屉顶层入口**离开浏览会话**后重进连接/文件夹**不把新层级追加到已离开的旧段上**；
  收掉旧段时它**之上**的非浏览层按原顺序恢复
  （因此返回落到来源列表/书柜，而不是直接首页）
- 抽屉顶层入口从不弹浏览层因而不动历史
  ⇒ 浏览页的返回处理器只在「栈顶之下紧邻是浏览层、且镜像与栈逐层一致」时接管

**根路由的返回键不直接退出 APP**：

- **根路由（首页在栈底、抽屉关着）的返回键不直接退出 APP**
- 第一次只弹一条轻量 Toast「再按一次退出」（不退出、不打断操作）
- **2 秒内**再按才真的退出（Activity finish，会话随之按既有口径清理）
- 超时、或离开根路由（进抽屉 / 进浏览层 / 进阅读器 / 首页被压在别的层之上）即重新计数
- 接管判据收在一处纯函数 + 时间窗状态机
- 子层级返回行为不变，各自由自己的处理器接管

**进程被杀后重建**：

- 回退栈由系统还原，浏览历史按还原出来的回退栈**整体重建（幂等）**，两者逐层对应
- 导航观测点一行给出回退栈深度 + 栈顶路由 + 历史游标

**设置页**：阅读模式、旋转三选一、双击倍率、启动页面五选项、
始终从第一页打开、音量键、主题

#### 导航过渡（票 #111）

**横向整屏滑入**（返回、进入、换书走同一条过渡、同一个方向）：

- 新屏从**右**滑入：水平位移 **+100%** → 0（整屏幅度）
- 旧屏往**左**滑出 100%——两屏同时动、位移相等 ⇒ 旧屏右缘恒等于新屏左缘，中间不露底
- 时长：**进阅读器 500ms**，其余（文件夹之间 / 返回 / 换书 / 冷启动淡入）**300ms**
- 曲线**匀速**；两屏都不做 alpha 变化（没有亮度交叉）
- 冷启动落地的纯淡入支：新屏不滑、起点 alpha 0，退场屏只淡出，300ms
- 位移幅度的分母是**这一屏的宽度**，不是屏幕宽度
- 系统「移除动画」为开时直接落在终值

**等页期间的呈现**：

- **就绪判据 = 任一页到位**：某一页画出了图、或确定失败、或空书，三者任一即就绪
  （失败也放行，否则失败文案与重试按钮会一直不可见；入口页在解码完成前离开组合也能就绪）
- **首批窗口**（有页可画、入口页还没到位；空书不算）：
  - 根背景取**主题背景色**，不是黑底
  - 入口页那一格是**空占位、不画进度圈**；其余未解码页照旧显示进度圈
- **整屏淡入**时长按**入口页那一页的图**定：
  - 图已在手（首帧命中解码缓存、自己不会淡）⇒ 整屏补 **150ms**
  - 图刚到、自己会慢慢显 ⇒ 整屏**立即**（0ms，只留图片自己那条）
  - 还没有图（失败 / 空书 / 首图未到）⇒ 整屏走 **150ms**
- 页内容那条「慢慢显」的层**只门控页内容**：菜单面板与跨书确认条在它之外 ⇒
  书已落地时点中区呼出菜单**立刻**可见；书还没落地时点中区不呼出
- 位图从无到有走 **150ms** 淡入（不是一帧全亮）

**衔接侧是「点了立刻滑」**：

- 导航在点击那一帧发生，**不等前置**
- 「打开书 + 首批解码」的前置与它的等待改到**阅读页侧**：上限 **1.5s**，到点由阅读页自己开书
- 前置工作归**会话级**作用域（发起那一屏被导航销毁也带不走它）
- 过渡期主线程单帧 > **32ms** 计数；判据：连续 10 次进出 > 32ms 的帧 ≤ 2，不过关不阻塞交付

**四条开书入口**（浏览页点击 / 启动还原 / 抽屉「阅读器」/ 阅读器内换书）都走**同一条开书入口通道**：

- 入口交「哪本书 + 这次请求算不算数的判据 + 怎么进阅读器」；通道负责领世代号、导航与会话级前置
- 四条都是**先导航再等**（前屏不保持到前置就绪；等页期间是主题背景色纯色）
- 前置在后台继续跑（发起侧被取消不停它）；失败不入槽
- 一份前置只属于**发起它的那次打开**：被顶替的世代不入槽；迟到的那份在阅读页自己开书落地后退役
  （旋转屏幕这类界面重建不再把它取走）
- 「这次点击算不算数」的守卫**各入口各一条**：
  - 浏览页 = 组合存活标志 + 「当前要开的那一本」
  - 另三条 = **栈项身份**（route + entryId；同 pattern 不同参数之间的离开也算离开）
- 导航已发生之后，「不许把 A 的句柄交给 B」由三件事共同承担：
  前置槽的「连接 id + 书 id」键、同键过期前置的世代判据、「只在这个阅读页在屏幕上时落地」

#### 窗口与系统栏

**窗口全幅绘制**：

- 窗口进入 edge-to-edge 并允许在挖孔/刘海区绘制，阅读器画面铺满到屏幕顶端与挖孔侧
- 列表类界面继续由 Scaffold + 顶栏消费系统栏 inset（不双重内缩）
- 贴底浮层（阅读菜单面板、跨书确认条）显式消费系统栏与挖孔 inset
- **例外**：阅读菜单面板在**手机竖屏档**不消费**底部** inset
  （裁决：面板底边贴屏幕下缘，底部内边距 = 滑条行半高 + 行距 = 18dp，
  使底部行上下两段各 36dp 成立），其余视口档左/右/下三边照旧消费
- 系统栏图标明暗跟随深浅主题

**阅读器沉浸**：

- 阅读器路由在场时隐藏状态栏与导航栏；**离开当帧就恢复**
- 隐藏与恢复**都按当前路由驱动**，而不是阅读页的组合存活期 ⇒ 换书时效果不重跑、
  旧页面的销毁不可能盖回新页面的隐藏
- 隐藏时边缘滑动仍能临时唤出系统栏、恢复时行为回到默认
- 系统栏隐藏后 `系统栏 ∪ 挖孔` 会塌成 0，贴底浮层的**底部 inset 因此分两支**
  （判据收在一处纯函数）

**系统栏占位**（底 inset > 0）：

- 用**真实栏高**（= 系统栏底 ∪ 挖孔底，与改动前逐像素相同）
- 边缘上拨**瞬态唤出**的那几秒是否也走这一支 **本机未验证（真机观察项）**

**栏缺席**（底 inset == 0）：

- 用「挖孔底 ∪ 24dp 最小留白」
- **手机竖屏档的阅读菜单面板不消费这份底部留白**
  （裁决：面板底边贴屏幕下缘，
  代价是底行连同其 48dp 命中带的下缘落进该区）

#### 名称与图标

**条目名称断行**：

- 名称按「能塞就塞」断行（最多两行、不省略号）
- 在 `]`、`-` 这类闭合/连接标点之后与数字字母交界处补零宽空格作额外断点
- 长度 ≥ 4 的 **ASCII 字母/数字串**在串内每 2 个字符也补一个断点
- 长词允许在词内断开、不引入连字符；3 字符以下与其它文字保持原子
- 并给名称文本指定贪心断行配置（API 33+ 生效）

**名称块高度**：

- 网格档的名称块**固定两行高**（固定两行 = 行数上限）
  —— 1 行名也占满两行，同一排格子因此等高、格底逐行对齐
- 列表档不固定（最小行数 1）

**启动图标**：

- 三层自适应图标（白底 + 深蓝环 + 「CV」字标；比例与色值见设计说明）
