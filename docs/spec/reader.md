## User Stories

> 本册含故事 23–42。

### 阅读器

23. 作为漫画读者，我想用条漫模式阅读（垂直连续滚动，可按页跳转：跳到下一页/上一页页首），
    以便看 webtoon 类作品
24. 作为漫画读者，我想用单页模式阅读并选择左→右或右→左（RTL）方向，以便看日漫扫描本
25. 作为漫画读者，我想在设置里切换阅读模式（菜单里不放切换入口），以便阅读期间不被误触
26. 作为漫画读者，我想让触摸区域按类型 3 划分，以便肌肉记忆一致
    - 屏幕纵向三等分，且两种模式、两个单页方向下规则完全统一
      （左区恒为上一页、右区恒为下一页，不随 RTL 镜像）
    - 左区 = 上一页（条漫 = 上一张图）
    - 中区 = 呼出菜单
    - 右区 = 下一页（条漫 = 下一张图）
27. 作为漫画读者，在第一页点左区、最后一页点右区触发上/下一本时，我想先在底部弹出确认条，
    点击该按钮才真正跳转，以便杜绝误触跳书
    - 整宽条、三等分三列
    - 中格 = 当前位置（如「第一页」）
    - 按钮格按方向取左/右一格 = 橙色跳转按钮（如「上一本书」）
      —— 首页方向在左格、末页方向在右格
    - 按钮格与触摸区列逐像素对齐、整格可点
    - 中格与另一侧空白格不做任何动作
    - 而阅读菜单底部的上一本/下一本按钮则直接执行、无需确认，以便明确意图时一步到位
28. 作为漫画读者，我要求相邻书的判定只由名称自然排序决定，以便上一本/下一本顺序可预期
    且到头有明确反馈
    - 与当前列表排序方式及方向都无关
    - 范围 = 同一目录（文件源）或同一系列（Komga）
    - 已到头时点击不置灰，而是弹提示「无上一本」/「无下一本」
      （该层本会话还没被列过时同一条提示——邻位未知期与「确实到头」表现相同）
    - 进入阅读器后**后台**补齐该层，补齐后邻位恢复
29. 作为漫画读者，我想点击屏幕中区呼出阅读菜单，以便界面干净且不打断阅读
    - 面板贴屏幕底部、半透明（不铺满全屏深色遮罩，当前页仍可见）
    - 含书名标题、跳页滑动条、当前页/总页数、上一本/下一本按钮
      （无返回按钮、无模式切换、无设置入口）
    - 书名标题与页码字号随面板内宽放大
      （标题 = 内宽 × 0.05 夹 18–24sp、页码 = 内宽 × 0.05 夹 16–24sp）
    - 标题紧贴面板顶部（上方留白 3dp）
    - 长书名**最多 3 行**（动态 1→3 行，行数变化只抬高面板、**不压缩预览条**）
    - 断行口径与浏览页条目名一致
    - 当前页/总页数与上一本/下一本在**同一行**、**三等分三列**
      （上一本在左 1/6 处、页数在正中 1/2、下一本在右 5/6 处，每列内容在自己列内居中）
    - 底部行**可见高 36dp**，命中带 48dp（**只向下挂**、不向上侵占滑条行）
30. 作为漫画读者，我想在打开阅读菜单时即看到全书页的横向预览条
    （滑动式、每格带页码、当前页高亮），以便不必先拖动就能看清附近几页
    - 拖动滑动条时预览跟随目标页、松手后回到当前页
    - 单击滑动条轨道与拖动等价——预览以该位置对应页为中心、随即跳到该页
    - 点击任意预览缩略图直接跳到该页、**菜单保持打开**，与滑动条跳页同一条落地路径
    - 跳页后**当前页缩略图落在预览区正中**，首页与末页除外——到头只能贴边
    - 条漫模式的「当前页」= 顶部可见页；已滚到书末且内容超过一屏时报最后一页
31. 作为漫画读者，我想双击放大，以便看清细节
    - 以双击位置为中心，倍率默认 2.0x、可设 1.5x–4.0x
    - 放大是约 240ms 的缓入缓出过渡、缩放与位移一起走完
    - **缩放后不窄于视口的那条轴**上双击点整段过渡不动
    - 页窄于视口的轴（单页模式横屏几乎必中）偏移由既有钳制公式决定、过渡中途可见漂移
    - 双指缩放与放大后单指平移仍是逐帧跟手，动画让位于手指
32. 作为漫画读者，我要求放大状态按页记忆，以便长篇细读时不用反复放大
    - 翻页/回翻不复位，仅再次双击恢复适屏（复位同样平滑过渡回 1.0）
    - 动画进行中再次双击/翻页以最新状态为准，不回跳、不错位
    - 且退出阅读器后放大状态丢弃（重开漫画看到原样）
33. 作为漫画读者，我想双指开合缩放（1x–8x、力度随手势），以便自由控制缩放
34. 作为漫画读者，放大后我想单指拖动平移
    （条漫 = 水平平移 + 垂直继续滚动；单页 = 限制在图片边界内），以便查看局部
35. 作为漫画读者，我想用蓝牙鼠标滚轮在阅读器内滚动页面（单页模式一格 = 翻一页），
    以便解放左手
36. 作为漫画读者，我想让鼠标左键等同触摸区域行为、右键与左键一致，
    以便只用鼠标也能完成全部阅读操作
37. 作为漫画读者，我想让鼠标后退侧键 = 浏览历史后退、前进侧键 = 浏览历史前进
    （前进不回到阅读器），以便导航符合系统习惯
38. 作为漫画读者，我想让 APP 适配全面屏返回手势（阅读器内不做返回按钮），
    以便符合现代安卓习惯
39. 作为漫画读者，我想用音量键翻页，以便单手阅读
    - 单页 = 翻一页；条漫 = 跳到下一页/上一页的**页首**
      —— 一次按压一页，可能跳过当前页尚未显示的部分
    - 单击一跳、长按连发每一发都跳一页
    - 到书首/书末不交还系统，而是就地弹出**跨书上/下一本确认**，
      按键仍被消费、不改系统音量
    - 默认开、设置可关
40. 作为漫画读者，我想打开设置开关「始终从第一页打开」后，打开任何书都定位到第 1 页，
    以便重读时干净开始
    - 且打开瞬间阅读进度即覆盖为第 1 页（进入马上退出也只算读了 1 页）
    - **例外**：前置还没到货就退出时不写——落地排在阅读页侧那次可取消的等待之后
41. 作为漫画读者，我想让阅读进度本地持久保存，以便任何来源的书重开时继续阅读
42. 作为漫画读者，Komga 来源的阅读进度我想与服务器双向同步
    （打开书时拉取定位、阅读中回传页码），以便手机/平板/网页多端无缝继续阅读

## Implementation Decisions

### 阅读页缓存

**页字节磁盘缓存**：

- 键 = 书 id + 页索引的 SHA-256 前 32 位十六进制，上限 200MB
- **最终一致**：达到上限时清理在后台分批进行，写入后可短暂高于上限
  - 超上限按修改时间从旧到新淘汰到上限的 80%
- 写入按「先写 `.tmp` 再改名」原子落盘（0 长度残留视为未命中）

**清理不在取页路径上**：

- 写入只累加一个字节计数；清理排到后台单线程分批执行
  - 一趟只删固定批量、有上界
  - 还没到目标线**且本趟确有文件被删**才再排一趟
  - 一个都没删掉就停到下次写入
- 因此「取一页要多久」与缓存目录里有多少文件无关
- 本进程内第一次写入会先核一次目录真实占用（目录跨进程存在，计数不然会偏低）

**内存层是两份独立预算的位图缓存**（按屏宽解码、RGB_565）：

- **页面位图 = max(4MB, 堆 1/8)**
- **封面位图 = max(4MB, 堆 1/16)**
- **互不淘汰**（阅读器一页几十 MB 时不会把封面整批淘汰）
- 命中即不再取字节

### 书与容器

**书的判定**：

- 一个目录**本层只有图片**才是书（打开 = 按名称自然序读本层全部图片）
- 本层有子文件夹或压缩包 ⇒ 它是**容器**
- 判定只有一处

**打开容器不递归合并**：

- 列出的只是它自己这一层的条目
- 子文件夹与压缩包各是一条独立条目（点一个读一个、各自是一本）
- 本层图片各自也是条目（点一张 = 从该张连读本层其余图片）
- 因此打开的页数只与本层有关、与下层书目数/总页数无关
- **打开容器只读本层图片、不并入下级**
  - **例外：本层无图的容器**——只含子目录、只含压缩包、或空壳
    —— 打开时抛错，界面给中文提示

**压缩包（CBZ/ZIP）**：

- **内部**按图片扩展名**全深度**收集
  （包内套一层书名目录是常见布局；包内分卷见非目标）
- 压缩包里没有图片时给出 0 页句柄，界面据此显示中文空态（不是一直转圈）

### 阅读菜单与预览条

**预览条**：

- 完整显示不裁剪
- 单格**宽度按该页真实比例**、**高度 = 预览条高 − 页数行**
  （页数在缩略图正下方居中）
- 缩略图**按预览条高向上取到 32px 整数倍**解码
  页数行占掉预览区一行
- 格内页码字号随**面板内宽**放大并夹在 12–16sp（基准是面板内宽，不是格宽）

**三档字号层级**（基准都是面板内宽）：

- 菜单标题 = 内宽 × 0.05 夹 18–24sp
- **>** 面板页码 = 内宽 × 0.05 夹 16–24sp
- **>** 格内页码 = 内宽 × 0.035 夹 12–16sp
- 正常档成立；**极端 fontScale 下**面板页码会降到「**≥** 格内页码」并**允许省略号**
  —— 下限绑格内页码字号以保证层级不破

**面板出现 / 消失**：

- 呼出时从**屏幕下缘往上滑入**、收起时**沿来路往下滑回**
- 时长 **出现 120ms / 消失 100ms**（出现减速型、消失加速型；出现起步缓 ⇒ 比消失长）
- 单击唤出菜单前有**双击等待窗口**（150ms，平台默认 300ms）——「点了到看见」≈ 静等 + 出现 = **270ms**
- 位移取整幅高 ⇒ 两端都完全落在屏幕下缘之外；面板的内容与几何不受影响
- 出现与消失的时长、曲线各只声明一处（消失曲线复用导航过渡的退场曲线）

### 进度规则

- 打开书 → 按「始终从第一页打开」开关决定落点（开 = 第 1 页且立即覆盖进度）
- 阅读中节流保存本地
- Komga 源额外双向同步
