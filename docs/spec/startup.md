## User Stories

> 本册含故事 43–49、50–54。

### 书柜与启动

43. 作为漫画读者，我想在书柜里按连接看到该连接的**根条目**，以便不逐本收藏也能有统一入口
44. 作为漫画读者，我要求书柜按连接分柜展示，以便库与库之间不互相污染
    - 同一来源的多个连接也不混排
    - 点某个连接**直接进该连接的浏览页根层**：与首页点连接同一路由、同一屏、
      同一排版与同一标题口径，不再有独立的「单柜」屏
    - 柜列表这一级在只有一个连接时同样保留
45. 作为漫画读者，我想在书柜里看到与浏览列表一致的**书条目**进度条，以便掌握全局进度
    - 绿 = 进行中、红满格 = 读完，不是红勾
    - 文件夹与系列没有进度，不显示
46. 作为漫画读者，我想设置启动页面，以便按当天心情选择起点
    - 选项：上次阅读的位置（默认）/ 上次停留的位置 / 书柜 / 阅读器 / 首页
47. 作为漫画读者，我要求「上次阅读的位置」在上次退出时正在看书才直接打开该书并定位到上次页码，
    否则退化为恢复上次停留的位置（顶层路由或浏览目录），以免每次打开都掉进同一本书
48. 作为漫画读者，「上次停留的位置」要恢复退出时所停留的位置，以便接着刚才的地方继续
    - 停在顶层路由（首页 / 书柜 / 设置）⇒ 恢复该顶层路由；停在浏览层 ⇒ 恢复**目录层级**
    - 停在阅读器 ⇒ 落回上次停留的浏览目录（不落进入阅读器前的那个顶层路由）
    - 排序方式与方向属于全局设置、本就一直保持，不参与恢复
    - 也不恢复滚动位置
49. 作为漫画读者，我想有一个首页展示来源/连接列表，以便从零开始选择去处
    - 首页只放来源入口，不放设置——设置只由导航抽屉到达

### 设置与周边

50. 作为漫画读者，我想设置页面旋转：竖屏 / 横屏 / 跟随系统（默认跟随），
    以便适配设备与阅读姿势
51. 作为漫画读者，我想主题深色/浅色跟随系统、也可手动覆盖，以便夜间舒适
52. 作为漫画读者，我想条漫模式背景为纯黑（OLED），以便省电护眼
53. 作为漫画读者，我想通过左侧滑出的导航抽屉（仅左侧）进入
    首页 / 阅读器 / 书柜 / 设置 四个入口，以便与 Perfect Viewer 的结构一致
54. 作为漫画读者，我想支持 jpg/jpeg、png、webp、gif（静态显示首帧）
    以及 CBZ/ZIP 压缩包与图片文件夹（ZIP 内部图片也按名称自然排序），
    以便覆盖我的全部库存

## Implementation Decisions

### 启动中转与退化

**启动判定期间停在中转页**：

- 判定内容 = 读设置项与上次状态 + 按 id 取连接 + 建来源会话
- 该页显示进度指示、**不响应抽屉边缘手势**
- **启动判定所需的落盘状态**（启动页面设置）在判定内、第一次挂起之前同步读完
- **本项只覆盖启动判定本身**；其余界面各自的设置读不在本口径内（它们已是内存读）

**导航**：

- 落地导航只做一次，但**还原后栈顶仍是中转页时补跑一次**
  （慢来源冷启动期间旋转、进程被杀后回到前台；否则该页没有任何出口）

**顶层落点**：

- 「上次停留的位置」在**顶层路由**上退出时记的是那个顶层路由，而不是很久以前那个浏览目录
- 写点挂在**路由**上，三态：
  - **记**：首页 / 书柜 / 设置
  - **清**：浏览层 / 阅读器（清只清顶层键，不动「上次停留的位置」的目录层级）
  - **不动**：其余路由（启动中转页、来源列表、连接列表等本次既不记也不清）
  - 进阅读器要清 ⇒ 在阅读器退出时仍落回上次停留的浏览目录（故事 48 的既有口径不变）
- 判定优先于目录层级：有顶层落点就落它，否则落「上次停留的位置」的目录层级，都没有则落首页
- 顶层路由只有一份清单，抽屉顶层入口集合由它派生

**退化**：

- 启动目标指向的连接已不存在时：
  - 浏览目标回落首页并**清掉** `StartupStore` 里那条不可用的「上次停留的位置」
    （读库本身失败时不清：那是暂时性故障，不等于连接被删）
  - 阅读器目标先退化为**上次停留的位置的目录层级**（`lastBrowsing`，不含顶层落点——这条链只读浏览记录），
    仍不可解析才回落首页
- 判定/建会话/导航抛预期外异常时**降级只落首页**
  （取消照常传播，不在取消后导航）
